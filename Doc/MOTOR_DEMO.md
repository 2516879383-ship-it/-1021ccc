## 工程与接线

- 打开 `Project/YH-F429.uvprojx`，目标 `LCD`，使用 Arm Compiler 5.06 update 7；继续使用原 DAP LINK 下载配置。
- 核心板 PC12 / UART5_TX → 电机 R/A/H（TTL RX）。
- 核心板 PD2 / UART5_RX ← 电机 T/B/L（TTL TX）。
- 核心板 GND ↔ 电机 GND；电机使用其型号要求的独立电源。
- 电机设置：Emm 固件、地址 1、115200、8N1、固定 0x6B 校验、控制命令应答 Receive。控制接口和使能配置应允许串口控制；本程序不会修改或保存电机配置。
- 以上对应用户确认的 TTL 电机版本。保留 RGB 屏、触摸、SDRAM、SWD 的原连接。

## 保留的演示实现动作（当前默认不执行）

按用户指定的空载、厂家参数执行，所有运动只运行一轮：

1. 屏幕等基础初始化后等待至少 500 ms，开始检查实时位置、转速和状态是否全部有效；再等待最多 3 秒建立通信。
2. 使能，并等待新的状态回包确认实际使能。
3. CW、1000 RPM、加速度 10，收到命令确认后计时运行 1000 ms。
4. 立即停止，要求连续 3 次新鲜转速绝对值不超过 5 RPM；最多等待 3 秒。
5. CW、1000 RPM、加速度 0、相对 32000 脉冲，立即执行、不缓存同步命令。
6. 等待位置发生变化、新的到位状态以及连续 3 次新鲜转速归零；最多等待 10 秒。收到命令确认或 9F 通知本身不代替这些实际测量。
7. 再停止、验证归零、失能并确认，进入 DONE；此后仍每 100 ms 一轮查询。

16 细分、200 步/圈时 32000 脉冲相当于 10 圈；程序不会设置或假定实机细分值来换算控制脉冲。屏幕实际位置采用 Emm 回包规则：带符号的多圈计数 ×360/65536，单位度；转速为带符号 RPM。

参数集中在 `User/motor/motor_demo_config.h`。需要单独复查查询回传时，可检出第二阶段提交 `6fa69fd`；它不启动运动。第三阶段 `f1fbc09` 只有速度演示。

## 屏幕字段

使用英文标签和片内字体，避免依赖外部中文字库。屏幕为 480×272，每 100 ms 检查显示内容，只绘制发生变化的行。

| 字段 | 含义 |
|---|---|
| DEMO | 当前演示步骤；DONE 或 FAULT 为本轮终态 |
| LINK | 位置、转速、状态三项都在 500 ms 内更新才为 ONLINE |
| POS / SPEED | 电机实际回传；未收到为 --，超过 500 ms 标记 STALE |
| ENABLE / IN POS | 状态标志 bit0 / bit1 |
| STALL / PROTECT | 状态标志 bit2 / bit3，不推断其他具体硬件故障 |
| RX / TX / BAD | 有效回包、成功提交发送、解析丢弃字节计数 |
| LAST ERR | 最后错误；进入故障流程后保留原故障原因 |
| RESULT | 最后一条控制命令结果；02 正确，E2 拒绝，EE 格式错误；FF 是软件超时、FC 是传输异常，均不是伪造的电机回包；-- 表示尚无控制结果 |
| RX AGE | 最近一次有效回包距今时间；每个测量值另有独立有效时间 |
| TOUCH | 当前/最近的触摸坐标，用于检查四角映射；不会触发运动 |

通信断开、命令拒绝、堵转/保护或动作超时会中止演示，并尝试一次停止和失能。只有获得新的速度/状态验证，才显示 FAULT / STOP CONFIRMED，否则显示 UNCONFIRMED。连接恢复后只恢复数据查询，不自动重跑；重新上电或复位才开始新一轮。

## 软件验证

在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File Scripts/test.ps1
powershell -ExecutionPolicy Bypass -File Scripts/build.ps1 -Rebuild
```

- 主机测试使用本机 MSVC `/W4 /WX`，直接编译实际协议、电机服务、自动演示与 UI 代码。
- 70 项断言覆盖命令字节、正负数、分片/粘包、噪声/帧尾/符号错误、帧内 6B、非当前查询回包不更新测量、查询重试、忙、迟到应答、时钟回绕、断线恢复、正常命令顺序、只执行一次、ACK 丢失不重发、ACK 与实际状态不一致、堵转、归零失败、位置不到位、静止样本去重。
- LCD 替身使用工程真实 Font16（11×16）数据，另验证 12 行显示、负的小数、无数据/过期标记、局部刷新及 480×272 边界，不代替实机视觉检查。
- Keil 完整构建 0 错误，仅原有触摸驱动的 8 个 #177-D 未使用符号警告。生成 `Output/YH-F429.hex` 和 `.axf`。
- 链接 map 确认 UART DMA 缓冲位于 `0x20000000` 片内 SRAM 区，不在 CCM 或 SDRAM；显存继续使用 `0xD0000000`。
