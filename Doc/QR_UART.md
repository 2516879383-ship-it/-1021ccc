# XM1605 串口接入：软件交付与实物联调

日期：2026-10-20；2026-10-21 增补 PB12 周期触发。基于 a01d1da 实施，直接扩展原 HAL 1.7.3 / Keil AC5 工程，没有重建 CubeMX 工程或升级 HAL。

**已完成软件实现、主机测试和 Keil 完整重编译；未烧录，未进行实物扫码、接线、电机或触摸验收。** 当前默认应用为扫码联调，电机仅查询地址 1。自动演示源码、配置、工程引用和测试完整保留，当前入口不执行演示。

## 1. 当前主程序

`main.c` 初始化屏幕、触摸、UART5、USART3 和 PB12 触发输出，再调用 `QrApp_Init`。每次循环调用 `QrApp_Process`，依次处理电机接收/只读服务、触摸按钮、二维码触发/接收/会话和当前页面。串口接收与页面独立。

- 上电自动进入第 1 次会话，默认二维码页，`WAIT CODE` 和 `--`；接收初始化失败显示 `UART ERROR`。
- 完整合法记录才设置 `valid`、发布一次接受事件并显示 `VALID / LOCKED`。相同码只累加 DUP，另一合法码累加 IGN 并提示 `IGNORED / LOCKED`，均不替换任务。
- 非法记录显示 `INVALID CODE` 与原因，等待中不显示历史成功；已锁定结果继续保留，错误单独显示。
- 10 秒未成功显示 `WAIT TIMEOUT`，仍持续接收，不表示设备离线。合法码随后仍可锁定。
- `RESCAN` 清除当前结果、待取接受事件、组帧状态和本机 DMA/软件积压数据，增加会话号并从零等待。累计计数及有效历史保留；相同码可在新会话再次接受。
- RESCAN 后先等待 CR/LF 或至少 250 ms 无字节间隙建立边界。按下后立即到达且尚无边界的首条记录可能被舍弃，屏幕显示 `SYNC BOUNDARY`；建议松手后稍等再扫描。
- `MOTOR` / `QR` 只切页，不重置会话或锁定。电机页明确显示 `READ ONLY - DEMO DISABLED`，没有运动按钮；左侧 READ ONLY 是标签。
- 按下边沿命中按钮，一次持续按住只触发一次；从按钮外按下再拖入不会触发。触摸按指点集合保持一次手势，所有手指释放后才允许下一次按下。按住时最多每 20 ms 读取触摸，运行期不再逐点阻塞打印坐标。
- 复位从第 1 次会话和 `--` 开始，不写 Flash。静默/拔线不能仅凭串口判断在线或离线。
- 不调用 `MotorDemo_Process`，不因扫码成功、失败、切页、超时、恢复或重新扫码发送运动/使能/失能命令。只读查询也不会停止已经由外部控制而运行的电机。

主控通过 PB12（J7 第 14 脚）周期拉低 XM1605 的 TRIG（pin 12，低有效）：当前配置每 1000 ms 输出一次约 800 ms 低脉冲、间隔 200 ms 高电平，由 `bsp_qr_trigger.c` 在主循环中非阻塞调度。**本版仍不发送模组配置或触发串口命令**；必须先把模组设为手动模式（默认；电平触发即可），周期低脉冲才等于“每次拍摄一次”。连续模式下 TRIG 是暂停/继续开关，不能与这个波形混用；命令触发模式需要另发串口指令，本版未使用。会话开始只表示主控接受结果，不代替模组的光学触发；触发波形和模组响应都需要实物验证。

### 建立输出契约的设置步骤（待操作）

先确认模组型号/转接板适用上述手册，保存现有参数或记录原始输出，再使用手册中的**设置码图片**逐项配置；本程序不自动恢复出厂、不写模块配置。

1. 系列手册第 2 章通讯接口，印刷页 49（PDF 页 58）：选择 `TTL-232串口模式`，等待模块初始化完成。USB-HID 或 USB 虚拟串口不能据此认定 TTL 同时有输出。
2. 印刷页 50～51：核对/设置 9600、无校验；按其串口参数表确认 8 数据位、1 停止位。
3. 第 3 章：**使用本程序的 PB12 周期触发时，选择手动模式（默认）并保持电平触发**；不要选择连续模式（连续模式下 TRIG 脉冲是暂停/继续开关，和本程序波形冲突）。如果不用 PB12 而希望模组自输出，才选择连续模式或感应模式。若必须主控命令触发，另核对 `XM160X指令_更新.xlsx` 和应答后再接入，本版没有猜测命令。
4. 第 6 章印刷页 75～76（PDF 页 84～85）：禁止前缀、后缀、Code ID；页 80（PDF 页 89）选择 CRLF、传输整个 Data；页 81 禁止 RF 信息；页 82（PDF 页 91）选择纯数据输出。
5. 用资料内 sscom 或已知 USB-TTL 先捕获原始数据。示例目标十六进制为 `31 35 36 2B 31 32 33 2B 35 31 36 2B 32 33 31 0D 0A`。这是预期样例，**不是本次实测记录**。

不选择快速 POS 模式来代替上述步骤：资料说明该模式会启用命令触发并关闭结束符。当前不支持无结束符、TAB 结束或带协议封装；若实物只能使用这些模式，应单独设计和测试后接入，不在收到第 15 字符时提前接受。

## 3. 模块/API 与恢复策略

| 文件 | 已实现职责 |
|---|---|
| `bsp_qr_uart.c/.h` | GPIO/时钟/UART/DMA/NVIC、IDLE/半满/全满搬运、溢出标记、前台恢复、RESCAN 丢弃积压 |
| `bsp_qr_trigger.c/.h` | PB12 推挽输出初始化、1000 ms/800 ms 非阻塞 TRIG 波形、上电先保持高电平 |
| `bsp_uart_callbacks.c` | 唯一 HAL RX 半满/全满、错误和 TX 完成入口；明确分发 USART3 / UART5，USART1 不走这些业务路径 |
| `qr_stream.c/.h` | 64 字节有界记录、CR/LF/CRLF、半帧超时、丢弃和边界同步；IDLE 不结束记录 |
| `qr_task_code.c/.h` | 无 HAL 的严格长度、分隔符、颜色、位置与集合校验；失败不改输出对象 |
| `qr_service.c/.h` | 当前/历史结果、会话、一次性发布、锁定、去重和错误统计 |
| `qr_app.c/.h` | 实际主循环联调入口；电机查询与扫码/触摸/显示协作 |
| `qr_ui.c/.h` | 默认扫码页、电机只读页、按钮命中、按下/释放、100 ms 变化行刷新 |

`QrTaskCode` 提供 `text[16]`、`colors[2][3]`、`positions[2][3]`。示例输出颜色 `[1,5,6] / [5,1,6]`，位置 `[1,2,3] / [2,3,1]`；第四组只表示第二批粗加工位置，未生成码垛动作。校验采用任务书规则：两批颜色各自为 1～6 内的三个不同数，集合相同；两批位置各为 1/2/3 的排列。

`QrService.data` 提供 `valid`、`history_valid`、`session`、`accepted_ms`、`accepted_seq`、历史时间及各类计数；业务可用 `QrService_TakeAccepted` 只取一次接受事件。当前联调入口只显示结果，没有自动动作消费者。新会话须通过 `BspQrUart_BeginSession` 同时丢弃传输积压，不能仅单独重置服务对象来保证硬件边界。

UART ISR 只记录/搬运，前台完成解析和绘图。错误先于 IDLE 清除检查，防止 SR/DR 读操作掩盖错误；前台通过 HAL Abort/DeInit/Init 恢复本路 DMA，不覆盖 UART5。恢复期间保留 SysTick 和电机 IRQ。接收重启失败每 100 ms 重试；UART/DMA 初始化本身失败则显示错误，修正配置后复位。

超长记录只计一次 OVF；软件队列满后冻结该队列的后续入队，前台丢弃整批受损数据。半帧超时、溢出和 UART 错误后均丢弃到下一 CR/LF，随后才接受新完整记录，因此恢复后第一条记录可能被用作同步而不接受；继续扫描即可。已锁定结果始终保留。空行与 CRLF 后面的 LF 不产生第二条记录。没有从噪声中截取合法子串、去空格或猜 ACK 格式。

时间戳来自 DMA 搬运批次，不是逐字节硬件精确时间。每次 Pump 有 512 次处理预算。默认 9600/8N1 时半个 DMA 缓冲约 133 ms；IRQ 必须在 DMA 覆盖前得到服务，任意长时间全局关中断/调试暂停造成的多圈覆盖不可能单靠 NDTR 完整恢复。软件测试不证明实物满负载时序。没有模组侧会话号，无法识别所有“模组在 RESCAN 前识别、之后才输出”的旧码；若实测遇到，需结合已核实的停止/触发机制处理。

PB12 触发由 `bsp_qr_trigger.c` 在主循环中非阻塞调度，不用中断和 HAL_Delay：上电先写高再切输出避免误触发，其后每 1000 ms 输出约 800 ms 低脉冲、200 ms 高间隙。周期触发与现有会话/锁定状态兼容：锁定后模组继续输出时只累加 DUP/IGN，不替换任务；RESCAN 后第一次完整输出仍可能被同步边界丢弃，下一周期输出即可接受。当前 800 ms 低电平是给默认电平触发模式留的拍摄窗口；若实测仍不足，在 `qr_config.h` 中增大 `QR_TRIG_LOW_MS` 或 `QR_TRIG_PERIOD_MS` 后重新验证（低电平必须小于周期，否则编译报错）；模组必须处于手动模式，连续模式下同一波形会变成暂停/继续切换。
