# 野火 F429 V1 多外设项目：已知信息与当前进度

更新日期：2026-10-19。

本文记录已知的硬件、工程状态、开发目标和待确认事项，作为后续开发的共同依据。标注“源码核对”的内容来自当前工程；“用户确认”表示用户报告的实物或运行情况；“候选方案”尚未完成接线和运行验证。

## 1. 项目目标

在野火 STM32F429 挑战者 V1 核心板上实现：

- 屏幕显示和少量触摸操作。
- 多电机通信。
- 舵机控制。
- 上位机信息回传。
- PMW3901 光流传感器数据采集。
- 二维码扫描模块接入。

目前采用野火配套 RGB 电容触摸屏，用户确认只有核心板，不使用野火底板。电机已由用户确认为 **X42S_V2.0 光耦版、Emm 固件、TTL 串口通信**；电机数量、固件版本号和当前通信参数仍待补充。舵机已确认是 **2 个、众灵 PM 系列资料对应的 PWM 控制、270° 舵机**；具体 PM 型号尚未明确，不影响先设计通用 PWM 驱动。

```text

    ↓

    ↓
```

### 6.2 PM 系列 PWM 舵机：本次资料核对

资料目录：`E:/工创赛/硬件说明/PWM舵机（PM系列）`。

主要依据：[众灵舵机使用手册](<E:/工创赛/硬件说明/PWM舵机（PM系列）/01-文档教程/众灵舵机使用手册-250508.pdf>)第 6、10 页，以及同目录快速上手图。

| 项目 | 手册信息及本项目采用方式 |
|---|---|
| 产品系列 | PM 代表 PWM 舵机；同一手册还包含 ZP 总线舵机，需区分适用章节 |
| 本项目数量/转角 | 2 个、270°，用户确认 |
| PWM 周期 | 20 ms，即 50 Hz |
| 有效高电平脉宽 | 500～2500 μs |
| 中位 | 1500 μs；对于 270° 舵机，手册定义对应约 135° |
| 信号线 | 橙色或白色 |
| 电源正极 | 红色 |
| 电源负极 | 棕色或黑色；与主控信号地共地 |
| 供电范围 | 随型号变化，不能仅凭“PM 系列、270°”确定最终电源规格 |
| 位置反馈 | 手册的 PM 型号表未提供角度回读；软件发出 PWM 不等于已经测得实际到位 |

手册第 6 页中，PM15S/D、PM20S/D、PM25S/D、PM30S/D、PM35S/D 和 PM45S 等 270° 型号列为 **5～8.4V**，PM60S/PM80S 列为 **5～13V**；180° 的 PM10S/D 又是不同范围。完整型号目前暂留空，可先按手册设计通用 PWM 驱动，确定实际供电和负载能力时再依据铭牌或购买规格补齐。

可用于驱动实现的名义角度换算为：

```text
pulse_us = 500 + angle_deg × 2000 / 270

0°   → 500 μs
135° → 1500 μs
270° → 2500 μs
```

该换算描述手册标称范围；机构安装后的零点、方向和允许行程需要另外标定。串口字符串指令不作为这两只 PM 舵机的直接控制方式，当前候选仍为两路定时器 PWM。

对已确认的 PM 系列 270° PWM 舵机，基本控制时序可以共用：两路均使用 20 ms 周期，每路独立设置脉宽。不同型号主要还需分别记录电源、电流/扭矩能力、实际方向和机械行程，不能用统一的 PWM 时序推断所有电气与机械规格相同。

在当前 180 MHz 主频、APB1 /4 的常规时钟设置下，TIM3 的计数时钟为 90 MHz。候选配置 `PSC=90-1`、`ARR=20000-1` 可得到 1 μs 分辨率和 20 ms 周期，随后用比较值表达脉宽；这只是后续实现参数，尚未写入工程。

手册第 26 页的 **TTL 版本**接线对应关系为：

```text
主控 TX  → 电机 R/A/H（TTL 接收端）
主控 RX  ← 电机 T/B/L（TTL 发送端）
主控 GND ↔ 电机 GND
电机 V+ / GND → 匹配型号要求的电机电源
```

若采用候选 UART5，则上述主控 TX/RX 分别为 PC12/PD2。R/A/H、T/B/L 是不同通信版本共用的端口标记，此处接法只对应手册中的 TTL 版本，不能将 RS485/CAN 接口按相同方式直接接 MCU UART。

多电机由同一 UART 总线按地址管理，应先设置不重复的设备地址。默认 Receive 应答只表示收到控制命令，不能据此判定实际运动完成；若需要到位或回零完成反馈，应按需求匹配 `Response` 配置和接收解析。实际接线、总线并接和应答时序仍按厂商多机接线图核对。

“光耦版”与“TTL 通信”分别描述输入接口形式和当前通信方式，不应混为一个参数。手册给出的脉冲输入电压范围不用于推断 TTL 通信引脚的允许电压，通信脚仍按 TTL 接口规格与接线图处理。

| 上位机回传 | USART1 | PA9 TX、PA10 RX |
| 多电机 TTL 串口总线 | UART5 | PC12 TX、PD2 RX；当前仅为候选 |
| 二维码模块 | USART3 | PB10 TX、PB11 RX |
| 光流 SPI | SPI1 | PA5 SCK、PA6 MISO、PA7 MOSI |
| 光流控制 | GPIO | PE2 CS、PE3 RESET；MOTION 可先按需保留 |
| 已确认的 2 个舵机 | TIM3 CH1/CH2 | PB4、PB5；需避免 JTAG 占用 PB4，保留 SWD |
| 后续扩展预留，非当前需求 | TIM4 CH1/CH2 | PB6、PB7 |

分配时应继续遵守已确认的板级占用：

- SDRAM 数据/控制线不可当成普通空闲 GPIO；本项目显示需要实际使用 SDRAM。
- RGB 显示占用 PA3、PD6、PC7、PB8/PB9、PE5/PE6 等引脚，不能照搬无屏程序的串口和 PWM 分配。
- 触摸使用 PD11/PD13，应避免重复安排复位、总线方向控制或其他中断输入。
- 核心板 USB 接口涉及 PB14/PB15；本候选方案没有用它们输出舵机 PWM。
- 核心板 USB 接口本身不是 USB 转串口；如果使用 USART1 连电脑，需要相应的 USB-TTL 设备。

当前电机方案按 TTL 串口规划，不按 RS485 方案安排方向控制。TTL 多机接线、逻辑电平、地址和应答时序仍应按电机厂商方案核对。

## 11. 单电机实施记录（以本节为最新状态）

本轮：UART5 PC12 TX / PD2 RX，单台地址 1，115200/8N1，Emm 固定 0x6B。

| 阶段 | 软件验证 | 实物验证 |
|---|---|---|
| 1：状态页与非阻塞调度 | AC5 完整重编译 0 错误，仅原有 8 警告 | 待实测 |
| 2：查询回传 | MSVC 43 项检查通过；AC5 0 错误、仅原有 8 警告 | 待实测 |
| 3：自动速度演示 | MSVC 55 项检查通过；AC5 0 错误、仅原有 8 警告 | 待实测 |
| 4：位置与完整流程 | 未实施 | 待实测 |

阶段 1：加入 HAL_Init，保留 180 MHz 及 LCD/SDRAM；屏幕默认改为已知的 4.3 寸 480×272。触摸 EXTI 仅置标志，主循环处理触摸；画板替换为 100 ms 局部更新的状态页。未接电机时显示 --，并保留触摸坐标供四角验证。触摸芯片仍以原可用 GT1151QM 驱动配置为基础，实际型号和四角映射待实测。

构建：`powershell -ExecutionPolicy Bypass -File Scripts/build.ps1 -Rebuild`。Keil/AC5 5.06u7，原基线已有 gt9xx.c 的 8 个 #177-D 未使用符号警告；新代码不得新增警告。

阶段 2：UART5 接口及循环 DMA 已加入（RX DMA1 Stream0/CH4、TX Stream7/CH4）。接收事件搬运至软件环形队列，主循环按长度解析；TX 使用持久缓冲。默认 100 ms 一轮位置/转速/状态查询；100 ms 应答超时、查询最多三次、失败后清理迟到数据再重试；控制命令不自动重发。UART 错误/溢出清理并恢复接收，显示过期字段及最后错误。数据缓冲由默认链接放在片内 SRAM。

测试：`powershell -ExecutionPolicy Bypass -File Scripts/test.ps1` 使用 MSVC `/W4 /WX` 编译纯 C 协议/服务测试，覆盖打包、正负值、分片/粘包、噪声、帧内 6B、应答、忙、超时、迟到数据与恢复；截至阶段 2 共 43 项检查。实物电机接线、波特率/校验/地址和显示数值仍待验证。

阶段 3：上电至少 500 ms 后等待单电机在线（最多再等 3 秒），确认使能后，以 CW、1000 RPM、加速度 10 运行 1 秒，停止并连续确认 3 次新鲜转速绝对值 ≤5 RPM，再失能。运行一轮后只读轮询；上电未连通、拒绝、超时或堵转进入故障流程，尝试停止/失能并用实际回包显示是否已确认。没有应答不等同已经停止。参数集中在 `User/motor/motor_demo_config.h`。全部动作时序非阻塞，运动指令不会因超时重发。

阶段 3 模拟测试新增：上电等待、完整速度流程、仅执行一轮、离线后恢复不自动重启、速度 ACK 丢失不重发、使能拒绝、堵转与不能归零。实物仍待实测；当前固件会在通信确认后自动执行空载 1000 RPM 演示。
