当前 HAL_UART_MspInit 位于 User/usart/bsp_debug_usart.c，按 USART1/UART5/USART3 实例分支。UART RX 半满、全满、错误及 TX 完成回调统一位于 User/usart/bsp_uart_callbacks.c，显式分发 UART5 和 USART3；原电机处理路径保留。

UART5 DMA 缓冲 256 字节，软件 RX 队列 512 字节，TX 持久缓冲已扩为 128 字节。七机版本链接 map 核对电机和二维码 DMA 缓冲均位于 0x20000000 片内 SRAM 区，未放在 CCM 或 SDRAM。F429 栈由 1 KiB 增至 4 KiB，供组包和中断使用；静态调用图与内存记录见 MULTI_MOTOR.md。

PB12 由 User/usart/bsp_qr_trigger.c 初始化为推挽输出，上电先保持高电平（不触发），主循环按 1000 ms 周期拉低 800 ms。模组 TRIG 为低有效输入，按规格书需要外部驱动电路；本程序只输出 3.3V 逻辑电平，不替代手册中的 10k 上拉、100Ω 串联和 100nF/TVS 保护。

触摸 EXTI 只通知 AppTouch_Notify，主循环调用 AppTouch_Process 执行触摸处理；SysTick 调用 HAL_IncTick。运行期触摸 I2C 超时已缩短，HAL 库内部仍存在其自身的等待路径。

### 3.3 当前应用行为

当前默认应用为二维码与七电机通信联调：`main.c` 调用 `QrApp_Process`，统一处理 UART5 七机调度、扫码、触摸与显示。启动只读，当前不调用 `MotorDemo_Process`。

- 一个 MotorBus 管理固定地址 1～7 的独立速度、位置、状态、字段有效期及错误；UART5 只有此调度器发送。正常查询每字段约 500 ms，掉线降频探测；上电仅查询。
- 已实现按地址使能、限时速度、三种脉冲位置模式、四轮 37 字节 0xAA 包、非阻塞缓存同步、抢占停止及故障处理。UI 仍以 MANUAL 为显式意图（READ ONLY 下不提交运动）；驱动层 API 不再强制 manual，供任务状态机直接调用。`MOTOR_TEST_CONFIGURED=0` 时位置/四轮/同步显示配置拒绝，但单轴 10 RPM/1 s 点动可用（`MOTOR_BENCH_JOG_ENABLED` 可关闭）；同步默认锁定；`UNKNOWN` 在新鲜零速/无故障反馈后自动恢复（可宏关闭）。具体启用与操作见 [MULTI_MOTOR.md](E:/工创赛/迁移野火板/Doc/MULTI_MOTOR.md)。扫码成功、错误、恢复、RESCAN 和切页均不触发电机动作。
- `motor_demo.c/.h`、`motor_demo_config.h`、原 `motor_ui.c/.h`、演示工程引用和既有测试完整保留。演示实现支持一次速度、停止、位置和失能流程，当前默认入口不执行；详细参数与历史行为见 [单电机说明](E:/工创赛/迁移野火板/Doc/MOTOR_DEMO.md)。
- USART3 循环 DMA 与 IDLE/半满/全满事件仅搬运字节，前台按 CR/LF/CRLF 组帧。严格校验 15 字符 `ddd+ddd+ddd+ddd`、两批颜色范围/不重复/集合相同以及位置排列，不截取噪声中的合法片段。
- 上电自动第 1 会话，默认扫码页 `WAIT CODE`、`--`。合法码一次发布并锁定；重复码和另一码不替换。RESCAN 丢弃本机旧缓冲，清空当前结果、增加会话；累计统计和有效历史保留，新会话可再接受相同码。
- 等待 10 秒显示 WAIT TIMEOUT，但继续接收；静默不判设备离线。UART/溢出/半帧超时会丢弃受损记录、重新同步，不覆盖已有锁定结果。10 秒/250 ms 是当前可配置联调值。
- RESCAN 后等待结束符或 250 ms 无数据间隙；损坏记录后丢弃到下一结束符。普通文本不能识别模组内部滞留后才输出的全部旧结果，限制见专用说明。
- MOTOR / QR 按钮只切页，二维码后台接收持续；电机页启动显示 READ ONLY / DEMO DISABLED，七行地址/角色与独立反馈，点行进入详情。新增 MANUAL、RUN ONCE、单轴/底盘/全体 STOP；退出手动模式请求停车。按下边沿处理、长按只触发一次，显示限频 100 ms 并只重绘变化行；沿用 Font16/Font24。
- 主控新增 PB12（J7 第 14 脚）触发输出：每 1000 ms 产生一次约 800 ms 低脉冲，对应 XM1605 TRIG 低有效；仍不发送模块配置/触发串口命令。“开启会话”只是主控接受数据，模组光学扫描参数仍待实物确认。**连续模式下 TRIG 是暂停/继续开关而不是单次触发**，需先把模组设为手动模式（默认）再使用本波形；手动电平触发模式下每个 800 ms 低电平即一次拍摄窗口。串口 9600/8N1 与触发时序均为软件初值，未实测。
- 周期触发与锁定会话兼容：锁定后模组继续输出只累加 DUP/IGN，不替换当前任务；RESCAN 新会话仍可能把重触发后的首条完整记录当作同步边界丢弃，下一次输出即可接受。
- 尚未实现机构回零、限位、机械标定、光流采集、舵机控制和比赛动作状态机；七电机功能仅完成软件验证，未烧录或进行实物联调，未作比赛 12 mm 字高验收。

扫码模块/API、接收边界、资料接线、设置码位置和逐项实物检查见 [QR_UART.md](E:/工创赛/迁移野火板/Doc/QR_UART.md)。
