### 2.2 屏幕资料与配置

产品参数图片记录：4.3 寸、480×272、5 点电容触控，PCB 尺寸 118.2×69.2 mm，RGB888 接口；5V 与 3.3V 同时供电。背光“200 mA 即可点亮”是图片标注，不是整屏实测功耗。图片标称 140 帧对应 F429 DMA2D 纯色打点测试，不代表本应用刷新率。

当前源码选择 GT1151QM 的 4.3 寸配置，LCD 默认 480×272，主程序使用 ARGB8888 图层。单层显存为 522240 字节，放在 SDRAM。触摸芯片实物型号尚未确认，宏选择不等于实物识别结果。

当前 HAL_UART_MspInit 位于 User/usart/bsp_debug_usart.c，按 USART1/UART5 实例分支。UART RX 半满、全满、错误及 TX 完成回调位于 User/usart/bsp_motor_uart.c，现有分支处理 UART5。

UART5 DMA 缓冲 256 字节，软件 RX 队列 512 字节，TX 持久缓冲 16 字节。已有链接验证记录指出 DMA 缓冲位于 0x20000000 片内 SRAM，未放在 CCM 或 SDRAM。

触摸 EXTI 只通知 AppTouch_Notify，主循环调用 AppTouch_Process 执行触摸处理；SysTick 调用 HAL_IncTick。运行期触摸 I2C 超时已缩短，HAL 库内部仍存在其自身的等待路径。

### 3.3 当前应用行为

主循环依次处理 UART5 数据、电机服务、单电机演示、触摸和 UI。当前不是七电机整车控制程序。

- 只创建一个 MotorService，地址取 MOTOR_DEMO_ADDRESS，当前值为 1。
- 固定 0x6B 帧尾，预期控制应答设置为 Receive；代码不会自动修改电机菜单配置。
- 支持单地址使能、速度、位置、立即停止，以及实际位置/转速/状态查询。
- 当前位置命令固定模式 00、同步标志 0。按所用手册，模式 00 是相对上一输入目标位置；绝对模式和相对当前实际位置尚未暴露为接口。
- 约每 100 ms 一轮位置/速度/状态查询，命令间隔至少 5 ms，应答超时 100 ms，查询最多三次；运动命令不因超时自动重发。
- 解析按地址、功能码、预期长度和帧尾处理，支持拆包/粘包；每个测量字段有有效标志和时间戳，超过 500 ms 标为过期。
- UI 每 100 ms 检查变化区域，显示数据、演示阶段、错误和触摸坐标；无数据时显示 --。
- 尚未实现七地址调度、聚合命令、同步触发、机构回零、限位、二维码通信、光流采集、舵机控制和比赛状态机。

**当前固件会在上电后通信确认成功时，自动对地址 1 执行一次速度和位置演示。**依据上述地址表，地址 1 对应前左轮；当前没有等待整车启动按钮的逻辑。

演示流程为：至少等待 500 ms → 通信确认 → 使能并确认 → CW、目标 1000 RPM、加速度档位 10，ACK 后计时运行 1 秒 → 停止并连续确认 3 次速度绝对值不超过 5 RPM → CW、目标 1000 RPM、加速度 0、相对上一目标 32000 脉冲 → 观察位置变化、新到位标志及连续速度归零 → 停止、失能 → DONE。目标 RPM 不等于已测得达到该转速。

出现通信、拒绝、堵转/保护或动作超时会中止，并尝试停止及失能。未取得实际回传确认时显示未确认；完成/故障后继续查询，不自动重跑。详细行为和已有测试说明见 [单电机演示说明](E:/工创赛/迁移野火板/Doc/MOTOR_DEMO.md)。

用户确认的电机 TTL 接法在对应手册中为：主控 TX → 电机 R/A/H，主控 RX ← 电机 T/B/L，主控与电机 GND 共地。光耦脉冲端与 TTL 通信端是不同接口，不能将脉冲端电压规格用于 TTL 端。
